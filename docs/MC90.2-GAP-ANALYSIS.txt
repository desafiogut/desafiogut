GAP 1 — [CRÍTICO] Política de Privacidade INACESSÍVEL
--------------------------------------------------------------------------------
Evidência (verificada em 15/08/2026):
- https://www.iubenda.com/privacy-policy/DESAFIOGUT -> HTTP 404 (política
  inexistente/expirada na iubenda).
- https://www.iubenda.com/privacy-policy/DESAFIOGUT/cookie-policy -> HTTP 404.
- https://desafio-gut.com -> NXDOMAIN no DNS global (8.8.8.8): o domínio
  custom NÃO está registrado/apontado. https://desafio-gut.com/privacy -> 000.
- https://silly-stardust-ca71bc.netlify.app/privacy -> 200, mas é o fallback
  SPA (redirect /* -> /index.html); NÃO existe rota React /privacy no App.jsx.
- O app referencia a política via iubenda em 3 pontos (TermosConsentimento.jsx,
  pages/Seguranca.jsx, pages/MercadoLances.jsx).

Impacto: requisito obrigatório da User Data policy (política válida no Play
Console E dentro do app). Sem URL pública válida, o app é rejeitado na revisão.

Ações:
1. (S1) Gerar texto atualizado da política.
2. Publicar a política numa URL pública estável e não-editável: opção A =
   recriar/atualizar a política na iubenda e corrigir os 3 links no app;
   opção B = criar página /privacidade no frontend (SPA) e usar a URL do
   Netlify/domínio custom. Custo: iubenda pode cobrar; página própria não.
3. Corrigir o domínio desafio-gut.com (registrar DNS/domínio ou remover a
   referência) — domínio não resolve no DNS global.
4. Registrar a URL final no Play Console (campo Privacy Policy) e garantir
   link no app.
Responsável: operador (custo de iubenda = ação com custo; validar antes).

--------------------------------------------------------------------------------
GAP 2 — [CRÍTICO] Link web de Eliminação de Contas inexistente
--------------------------------------------------------------------------------
Evidência: função delete-account existe e funciona (in-app OK), mas NÃO existe
um recurso web externo dedicado publicado; o campo "URL de eliminação de
contas" do Play Console não tem URL para apontar.
Impacto: requisito obrigatório (User Data policy — Account Deletion): o link
web DEVE ser informado no Play Console; sem ele a revisão falha.

Ações:
1. Criar página web pública de eliminação. O SPA JÁ TEM a rota
   /excluir-conta (pública, sem gate de consentimento) — basta publicá-la
   numa URL estável (https://desafio-gut.com/excluir-conta após corrigir o
   domínio, ou https://silly-stardust-ca71bc.netlify.app/excluir-conta).
2. Registrar a URL no campo "Account deletion" do Play Console.
3. Documentar no relatório S3.
Observação: a rota /excluir-conta é funcional e leva ao fluxo de exclusão
(ExcluirContaModal -> POST delete-account). Validar em dispositivo real.

--------------------------------------------------------------------------------
GAP 3 — [ALTO] Classificação financeira/cripto -> possível exigência de conta
        ORGANIZAÇÃO (política de julho/2026, efetiva 30/09/2026)
--------------------------------------------------------------------------------
Evidência: "Preview: Play Console Requirements" (1.1) exige registro como
organização para serviços financeiros, incluindo carteiras de software de
criptomoeda e exchanges. O DesafioGUT usa embedded wallets Privy (carteira
Ethereum criada no login), assina transações on-chain e processa PIX via
Mercado Pago. O app NÃO é exchange nem carteira autônoma — a wallet é
mecanismo interno de assinatura de lances; a compra é em R$ via PIX.
Impacto: risco de o Google classificar o app como serviço financeiro e exigir
conta organização (D-U-N-S, documentos da empresa) — ou de rejeição durante a
revisão se a declaração financeira for inconsistente.

Ações (decisão do operador — sem custo imediato):
a) Preencher o "Financial features declaration" declarando o uso de
   pagamentos (PIX via Mercado Pago) e transações on-chain, SEM declarar o
   app como exchange/carteira de cripto (não é o propósito do app);
b) Preparar, caso o Google peça, documentação de que a embedded wallet é
   infraestrutura de assinatura (não um serviço de custódia/exchange);
c) Alternativa: migrar a conta para organização usando o CNPJ do Grupo
   União e Trabalho (23.040.066/0001-00) — exige D-U-N-S e documentos;
   validar custos antes.
Recomendação da auditoria: começar com conta pessoal + declaração financeira
precisa; migrar só se o Google exigir.
