  • R18-D: a Carteira mantém o layout actual (variante A, «Fiel ao actual»).
  • R18-E: menos texto pequeno e técnico; fica só o que ajuda a decidir.
  • R18-F: o Início mantém o layout actual (variante A), com os 4 tiles: Saldo, Passe Desafio, Lances Únicos e Total de Lances.
  • R18-G: a rolagem lateral é a de hoje (MC99): uma edição de cada vez, a 100% da largura.
  • R18-H: o Menor Lance Único fica limpo, com 3 vidros; o vidro da edição com o lance foi aprovado.
