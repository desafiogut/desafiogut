Mockups v2 — MLC + OP coerentes

As duas frentes do DesafioGUT passam a falar a mesma língua visual. Nada aqui está implementado — são propostas de design para o operador escolher. Cada aba tem 3 variantes; escolhe-se uma de cada.

Como usar

  1. Abra o Menor Lance Único e o Ofertas Programadas (links abaixo).
  2. Em cada um, carregue em A, B ou C para trocar a variante — a mesma tela, três desenhos.
  3. Use 375 / 768 / 1024 para ver no telemóvel, no tablet e no computador.
  4. Em baixo, à direita, há a auditoria ao vivo: toque ≥ 48 px e Regra 1 (texto dentro de vidro). Se estiver a verde, não há violações.
  5. Diga qual variante quer de cada aba no fim. O Início não se escolhe — é só a prova de que as duas convivem.

A conclusão é uma só: o conteúdo já era o mesmo nas duas abas — o que divergia era a roupa. Era daí que vinha a sensação de «duas apps».

Recomendação do Hermes

Menor Lance Único → A, com uma ideia roubada à B: o cronómetro acima do prêmio (é informação, não decoração).
Ofertas Programadas → A, com a barra de progresso da B (grossa, com o número grande) — a aba existe para juntar pontos e o progresso tem de se sentir.
Variante C (2 colunas / cards compactos) só compensa se o operador usar sobretudo o computador; no telemóvel a diferença é nula.

Motivo de fundo: as duas abas são superfícies Operate. O mínimo que muda e já entrega coerência é sempre a escolha mais segura — daí a A como base.

O que NÃO foi tocado

  1. Nenhum ficheiro do app. Zero alterações em src/, netlify/, scripts/. É design, não implementação — a implementação é um UTAC próprio depois de o operador escolher.
  2. Os mockups aprovados da série 107a. Os originais (menor-lance-unico.html, ofertas-programadas.html, inicio.html…) ficam onde estão, intactos. Esta pasta é mlc-op-v2/, ao lado deles. Nada foi substituído.
  3. Os valores. Raio, espaçamento, cores e tipografia vêm do tokens.css da série 107a — não houve paleta nova. Se a coerência se fizesse com cores novas, teríamos duas famílias outra vez.
