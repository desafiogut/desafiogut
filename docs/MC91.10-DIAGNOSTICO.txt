2. MAPA DO FLUXO FINANCEIRO REAL (leitura de codigo, netlify/functions)
----------------------------------------------------------------------
A) COMPRA DE SENHAS (fluxo real em producao):
   iniciar-pagamento (POST, sem auth; {endereco, qtd}) -> pedido PIX MP
     (qrCodeText/qrCodeImage + JWT de pedido TTL 15min)
   -> operador paga o PIX (app bancario)
   -> confirmar-pagamento (POST; {token}): verifica MP (blob mp-aprovados do
     webhook ou API live) -> status approved -> CREDITA SALDO R$ (blob saldo-rs)
     [Modelo dual: PIX credita R$, NAO senhas diretamente]
   -> comprar-senhas (POST; JWT lance-auth; {endereco, qtd}): debita R$ 2,00 x
     qtd do saldo-rs e chama adicionarSenhas ON-CHAIN (coordenacao/EOA paga o
     gas) -> saldoSenhas[usuario] += qtd (contrato LeilaoGUT mainnet
     0x0052477A8CA81BCAF4a60e21e635F9e00a5d16cd).
   -> Idempotencia: pedidos-pagos (blob). Reembolso automatico em falha
     on-chain (best-effort; TX_PENDENTE nao reembolsa -> reconciliacao).

B) LANCES (fluxo real em producao — mainnet):
   CardLance.jsx: em MAINNET, TANTO "flash" QUANTO "programado" usam o MESMO
   ramo -> POST /lance-relampago (JWT lance-auth via /auth-lance, assinatura
   EIP-191 da carteira Privy) com {endereco, valorCentavos, edicaoId,
   idempotencyKey}:
     - debita saldo R$ (blob saldo-rs; minimo 1 centavo, max R$ 9.999,99)
     - mainnet: comprometerLance on-chain (coordenacao assina; so o HASH do
       valor vai para a cadeia — keccak256(abi.encode(valor, endereco)))
     - valor real -> data-store (Key-Per-Bid; blobs ou Supabase via fachada)
   -> Fecho: consolidar-lances (admin): apura MENOR LANCE UNICO off-chain
     (apurarMenorUnico) e publica consolidarResultado via Flashbots (EIP-712 +
     edicaoNonce anti-replay).

C) SENHAS ON-CHAIN: NENHUMA function de producao CONSOME saldoSenhas em lances.
   darLance(idEdicao, valor) (que consome 1 senha) e chamado pelo frontend SO
   no caminho legado (Sepolia/localhost, MAINNET=false). Em mainnet o lance
   (inclusive "programado") debita R$. A UI de programado ainda exige
   saldoSenhas > 0 para HABILITAR o botao (gate visual) — mas o debito real e
   R$.
