## 2. PLANO DE EXECUÇÃO (MC89.16, 1–2 sessões)

### S1 — Endpoint de resumo (GET /admin-financeiro-resumo, operador+)

Já existe parcialmente. O `admin-series` devolve séries diárias de receita. O
que falta é um endpoint de RESUMO que agregue tudo num único pedido:

Entrada: `?periodo=30d`
Saída:
```
{
  totalRecebidoCentavos: 4400,
  totalEmCirculacaoCentavos: 975,   // soma de saldo_rs
  totalCreditos: 18,
  totalDebitos: 0,
  cotasVendidas: 0,
  receitaCotasCentavos: 0,
  saldoEoa: { eth, bloco },          // delegado ao admin-onchain (R7)
  creditosPorDia: [...],             // delegado ao admin-series (já existe)
  periodoDias: 30,
  geradoEm
}
```

Gate: operador+. Cache: 45s.

IMPLEMENTAÇÃO: juntar admin-series + uma query de agregação ao Supabase. O
saldo da EOA NÃO entra neste endpoint (R7: não agrupar Postgres com RPC).
O frontend chama admin-onchain em paralelo.

### S2 — Endpoint de transações (GET /admin-financeiro-transacoes, operador+)

UNION de saldo_rs_creditos + saldo_rs_debitos, ordenado por criado_em DESC,
paginação por cursor.

Entrada: `?tipo=credito|debito|todos&desde=&ate=&antes=&limite=`
Saída:
```
{
  transacoes: [{
    id, quando, endereco, tipo, valorCentavos,
    fonte,            // "confirmar-pagamento" | "webhook" | "ajuste-admin"
    saldoDepoisCentavos
  }],
  resumo: { entradas, saidas, liquido },
  proximoCursor
}
```

Gate: operador+. Sem cache (transações podem chegar a qualquer momento).

### S3 — Endpoint de relatório (GET /admin-financeiro-relatorio, admin+)

Exporta CSV com as transações do período. GET porque é leitura e o browser
descarrega diretamente. A exportação é registada em admin_logs (exportar dados
financeiros é auditável mesmo sendo leitura).

Gate: admin+. RL: 5/min.

### S4 — Frontend (GestaoFinanceira.jsx)

Três secções:

**Resumo** (4 cards no topo):
- Total recebido (PIX): R$ 44,00 (calculado)
- Em circulação: R$ 9,75 (calculado)
- Saldo EOA: 0.xxx ETH (admin-onchain, carrega em paralelo)
- Cotas vendidas: 0 (placeholder para quando houver)

**Transações** (tabela paginada):
- Colunas: Data, Endereço (truncado), Tipo (Crédito/Débito), Valor, Fonte, Saldo após
- Filtros: período, tipo
- Botão "Exportar CSV"

**Gráfico**: reutilizar `GraficoLinha` (MC89.7) com os dados de `admin-series`
