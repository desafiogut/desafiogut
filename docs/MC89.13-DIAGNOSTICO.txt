### Campos disponíveis por tabela

cotas:
  cliente_id: text (É o endereço Ethereum quando começa com 0x)
  endereco:   text (VAZIO em 7/7 — confirmado. A carteira vive em cliente_id)
  cnpj:       text (7/7 preenchido — é o CNPJ do lojista)
  email:      text (3/7 preenchido)
  categoria:  text
  vendida:    boolean
  payload:    jsonb (contém empresa, tipo, segmento, valor, etc.)
  criado_em:  timestamptz
  atualizado_em: timestamptz

  → Nome do cliente = payload->>'empresa' (não é coluna própria)
  → 2 de 7 cotas têm cliente_id = "cnpj:…" (não são endereços)

saldo_rs:
  cliente_id:     text (endereço Ethereum)
  payload:        jsonb (contém centavos)
  atualizado_em:  timestamptz
  → Não tem nome, não tem e-mail, não tem criado_em

saldo_rs_creditos:
  pedido_id:  text PK
  payload:    jsonb (endereco, fonte, valorCentavos, saldoAntesCentavos,
               saldoDepoisCentavos, processado, processadoEm)
  criado_em:  timestamptz
  → O endereço está em payload->>'endereco'
  → Não tem nome, não tem e-mail

lances (Supabase):
  → 0 linhas. Os lances vivem em Blobs (relâmpago) ou no contrato (programado).
  → Não é fonte para a lista de utilizadores.

### Quantos utilizadores únicos?
