## 2. O que MEDI antes de parar (para a próxima sessão não partir de suposições)

```
undici como modulo:      DISPONIVEL  (Agent: function, fetch: function)
Node:                    v24.14.1  (fetch global: function)
o guard hoje:            fetch simples — SEM dispatcher
Deps declaradas das funcoes: @netlify/blobs, @netlify/functions,
                             @opentelemetry/instrumentation-http, @sentry/node,
                             @supabase/supabase-js, aws-sdk, ethers, jose
                             (undici NAO esta declarado — medir se e built-in ou transitivo)
```

**A correcção é tecnicamente viável nesta stack.** A forma (Opção B do MC, a preferível porque
preserva HTTPS/SNI naturalmente):

```js
import { Agent } from "undici";
const agente = new Agent({
  connect: {
    lookup: (hostname, opts, cb) => {
      dns.lookup(hostname, opts, (err, endereco, familia) => {
        if (err) return cb(err);
        // VALIDAR AQUI — no momento da ligacao, com UMA so resolucao.
        // Literal IPv6 nunca chega aqui (a 5. ger. recusa antes).
        // IPv6 resolvido por DNS: decidir (a Opcao A ignora-os — e o que falhou).
        // Se for bloqueado -> cb(erro), a ligacao NAO acontece.
        cb(null, endereco, familia);
      });
    },
  },
});
// e no fetch: fetch(url, { dispatcher: agente, redirect: "error", ... })
```

O TOCTOU desaparece porque **passa a haver UMA só resolução — a nossa** — e ela acontece no
momento da ligação, não antes.

## 4. Avaliação de risco (do MC, e concordo) — o que está em jogo

A app corre em Netlify Functions (Lambda isolada). O alvo de maior valor do SSRF é a **metadata
cloud** (169.254.169.254), que pode expor **credenciais IAM temporárias**. Se a role tiver
permissões, isto é crítico — e a exploração está **aberta e medida em produção** (via nome
prefixado).

**Não desactivei o `img-proxy`**: o MC proíbe fazê-lo sem autorização, e é uma decisão sua.

## 5. A decisão que precisa de si

| opção | o que implica |
|---|---|
| **(a) 7.ª geração numa sessão limpa** (recomendada) | desenho medido e pronto no §2; PoC com isco local primeiro; passos do MC (testes, mutações, validador, deploy) com orçamento para os completar |
| **(b) desactivar o img-proxy** | usa-se `<img src>` directo e perde-se o proxy de imagens externas; elimina a superfície em vez de a tratar |

**Enquanto nenhuma for aplicada, o SSRF continua aberto em produção** — e está registado assim.
