# MC102.0 — SEG0: Frente A, `@netlify/blobs` 8.2.0 → 10.0.0 (2026-09-29)

> ⛔ **ERRATA (SEG3, ronda 1).** Este SEG0 leu a API pelo `.d.ts` e pelo `getConditions`, e **não pelo `makeRequest`**. Na 10.0.0 (e até à 10.4.x) o **`setJSON` não envia o `If-Match`**: espalha as condições. Só o `set` as aplica. E com condição, qualquer estado ≠ 412 devolve `modified:true`, em todas as versões até à 11.1.1. A versão 10.0.0 mantém-se, porque o `set` funciona nela, e o `gravar()` passou a usar o `set` (`3730c6c`). Ver `MC102.0_SEG3_VALIDADOR.md`.

**Veredito: SEGUIR (com ressalva de produção declarada).**

## 0.1 PoC e API

- **Versão mínima com CAS = 10.0.0** (SEG-1 §-1.4: `npm pack` de 8.2.0 · 9.0.0 · 9.1.6 · 10.0.0…; `onlyIfMatch` aparece pela primeira vez na 10.0.0).
- **Assinatura exacta (10.0.0, `dist/main.d.ts`):**
  - `setJSON(key, data, options?: SetOptions): Promise<WriteResult>`
  - `SetOptions = BaseSetOptions & ({ onlyIfNew?: boolean } | { onlyIfMatch?: string })`
  - `WriteResult = { etag?: string; modified: boolean }`
- **O cliente ignora um `onlyIfMatch` falsy** (`dist/main.js`, `Store.getConditions`): `if ("onlyIfMatch" in options && options.onlyIfMatch)`. Com etag `undefined` a escrita sai **incondicional e sem erro**. Por isso o `gravar()` recusa escrever sem etag.
- **PoC com a biblioteca REAL** contra o `BlobsServer` dela (`scratchpad/_poc-mc1020-*.tmp.mjs`, retirados do repo):
  - 10.0.0 com chave `pedido:abc-123` (tem `:`): **HTTP 500** no primeiro `setJSON`. É o bug de Windows corrigido na 10.0.2 («Encode blob key parts before saving to disk on windows»). Com chave sem `:`, funciona.
  - Na 10.0.0 **e** na 10.4.4, o `getWithMetadata` do servidor local devolve `etag: undefined` (o `get` do servidor não envia o header). O `onlyIfMatch: undefined` passa então a escrita incondicional: o etag velho escreve e uma chave inexistente é criada. **Isto é o servidor local de desenvolvimento, não o serviço de produção.**
- **Documentação oficial** (docs.netlify.com, Netlify Blobs): `getWithMetadata` devolve «`etag`: an opaque quoted string…». `onlyIfMatch`: «the write will only succeed if the entry exists and has an ETag matching this value». Diz também: «**Last write wins** … Netlify Blobs does not include a concurrency control mechanism», o que confirma a necessidade do CAS.
