## Achados → o que foi feito (commit `de3ead6`, deploy `6abc4c68…` ready)
1. ⚠️ **Store em falha → 200 `ignorado`, evento perdido.** Isto refutava a frase do meu log SEG1-3 («o store indisponível dá 503»; pelo webhook era inalcançável).
   → **CORRIGIDO.** `encontrarPedidosPorRastreio` é **estrita**: `abrirStore` nulo, erro no `list()` ou erro nos `get()` propagam, e o webhook responde **503 `store_indisponivel`**.
2. ⚠️ **Dois pedidos com o mesmo código → só o 1.º recebia eventos.** Era uma decisão de produto, e foi perguntada: **DEC-102.1b-11 «Gravar em todos»**.
   → **CORRIGIDO.** O webhook grava em todos os que casam, cada um pelo seu CAS. Se algum falhar → 503, e o reenvio é seguro (quem já gravou deduplica). A resposta passa a `{ok, pedidos:n, duplicado}`.
3. ⚠️ **Script E2E:** o `env:list` carregava **todos** os segredos de produção para memória, e o `FRENET_TOKEN` real era enviado ao webhook.
   → **CORRIGIDO.** O script usa só `env:get FRENET_WEBHOOK_TOKEN` para ver a presença, e o envio do token real foi retirado.
   - ⚠️ **Defeito novo apanhado por medição antes de correr:** para uma variável **ausente**, o `netlify env:get` escreve «No value set in the production context…» com **exit 0**. Um teste de «saída não vazia» dava **DEFINIDO falso**. O script passou a reconhecer essa mensagem.
   - O script foi **re-corrido** com o código corrigido em produção: **VERDE 17/17** (1708 ficheiros e 131 chunks sem o token).
4. ℹ️ O `definirRastreio` (MC102) apaga `rastreio.eventos` quando é chamado de novo com o mesmo código. → **NÃO corrigido:** é código de outro MC, fora do escopo. **Pendente.**
5. ℹ️ Data ilegível que chega primeiro fica como «a mais recente». → **CORRIGIDO** em `construirTimeline`, com teste nas duas ordens.
   - ⚠️ A minha 1.ª versão da correcção **estava errada** (`!(+∞ >= t)` nunca substituía). Apanhei-a ao reler, antes de correr, e reescrevi-a com `Number.isFinite` explícito.
6. ℹ️ O mesmo instante com outro fuso ISO passava a deduplicação. → **CORRIGIDO:** a lib grava a `data` em **ISO UTC canónico** (`toISOString`). A dedup é por instante; ilegível → `null`.
7. ℹ️ Um evento expulso (acima de 50), se reenviado, volta a entrar. → **Não corrigido** (raro). Registado.
8. ℹ️ O webhook não confirma que a transportadora do pedido é Correios; o A1 nunca vem da Frenet; listar por POST é O(N). → Registado (por desenho / DEC-10).
