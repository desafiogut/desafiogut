--- A) OG IMAGE ------------------------------------------------------------------
A1. Criar asset OG opaco 1200×630 (proporção 1.91:1) a partir do rosto do GUTO.
    guto-login.png é 512×512 TRANSPARENTE — impróprio direto para OG (fundo
    transparente vira preto/branco imprevisível nos scrapers). Compor sobre fundo
    navy da paleta oficial (#050818). Comando sugerido (sharp, Node):

      node -e "const s=require('sharp');(async()=>{
        const face=await s('public/assets/guto/guto-login.png').resize(560,560,{fit:'contain',background:{r:0,g:0,b:0,alpha:0}}).toBuffer();
        await s({create:{width:1200,height:630,channels:4,background:{r:5,g:8,b:24,alpha:1}}})
          .composite([{input:face,left:70,top:35}])
          .png().toFile('public/assets/guto/og-image.png');
      })()"

    (Opcional: adicionar logo/tagline à direita — mas fora do escopo mínimo. Se
     quiser texto embutido, gerar com @napi-rs/canvas ou compor um PNG de título.)
    Alvo de peso: < 300 KB. Formato PNG (ou JPG para menor peso).

A2. Adicionar ao <head> do index.html (URL ABSOLUTA obrigatória):
      <meta property="og:url"          content="https://silly-stardust-ca71bc.netlify.app/" />
      <meta property="og:image"        content="https://silly-stardust-ca71bc.netlify.app/assets/guto/og-image.png" />
      <meta property="og:image:width"  content="1200" />
      <meta property="og:image:height" content="630" />
      <meta property="og:image:alt"    content="GUTO — DesafioGUT" />
      <meta name="twitter:card"        content="summary_large_image" />
      <meta name="twitter:title"       content="DesafioGUT — O Menor Lance Único Ganha" />
      <meta name="twitter:description" content="Dê seu lance no DesafioGUT. Menor valor único ganha o produto." />
      <meta name="twitter:image"       content="https://silly-stardust-ca71bc.netlify.app/assets/guto/og-image.png" />

    CSP: scrapers (WhatsApp/Facebook) NÃO aplicam a CSP da página → nenhuma mudança
    de CSP necessária para o OG. (O domínio já está em img-src de qualquer forma.)

--- B) FAVICON -------------------------------------------------------------------
B1. Gerar ícones a partir do rosto do GUTO. Para o quadrado minúsculo, um recorte
    um pouco mais fechado que guto-login.png fica mais legível. Comandos sugeridos:

      # PNGs de favicon (transparente) + apple-touch (fundo navy p/ contraste no iOS)
      node -e "const s=require('sharp');(async()=>{
        await s('public/assets/guto/guto-login.png').resize(32,32).png().toFile('public/assets/guto/guto-favicon-32.png');
        await s('public/assets/guto/guto-login.png').resize(180,180)
          .flatten({background:{r:5,g:8,b:24}}).png().toFile('public/assets/guto/guto-apple-touch-180.png');
      })()"

      # favicon.ico real na raiz de public (16+32+48). Requer 'png-to-ico' OU ImageMagick:
      #   npx png-to-ico public/assets/guto/guto-favicon-32.png > public/favicon.ico
      #   (ou) magick guto-login.png -resize 48x48 -define icon:auto-resize=16,32,48 public/favicon.ico

B2. Atualizar index.html (substituir as 2 linhas existentes + adicionar .ico):
      <link rel="icon" type="image/png" sizes="32x32" href="/assets/guto/guto-favicon-32.png" />
      <link rel="apple-touch-icon" href="/assets/guto/guto-apple-touch-180.png" />
      <link rel="icon" href="/favicon.ico" sizes="any" />   <!-- favicon.ico na raiz -->
