1. DESVIOS DELIBERADOS DO PLANO (com justificativa)
--------------------------------------------------------------------------------
• TypeScript → JavaScript: o projeto NÃO usa TS (sem tsc; arquivos .jsx; vite).
  Implementado em .js/.jsx.
• jobId + endpoint /status-credito → POLLING ON-CHAIN por txHash: o backend do
  MC59.5 devolve `txHash` (NÃO um jobId) e não há store de status por job. O sinal
  de verdade é on-chain (o frontend já lê a cadeia). Poll do receipt por txHash =
  puro frontend (fica no R1), sem criar endpoint backend. Mais simples e robusto.
• Timeout ≠ "failed": o pseudo-código do plano marcava status='failed' no timeout
  (errado — a tx pode confirmar depois). Uso um estado `timeout` distinto, com
  mensagem "pendente, acompanhe/contate suporte".
• Testes: NÃO há runner de teste React no projeto. Extraí a LÓGICA de polling para
  um módulo PURO (creditoPolling.js) testado com node:test (satisfaz R4 na parte
  de risco). Hook/componente/wiring são validados por build + esbuild transform.

2. O QUE FOI IMPLEMENTADO (R1: só frontend)
--------------------------------------------------------------------------------
• src/lib/creditoPolling.js (PURO): aguardarConfirmacaoCredito({verificar, sleep,
  cancelado, maxTentativas, intervaloMs}) → repete verificar() até confirmado/
  revertido ou timeout; erro em verificar = pendente (re-tenta); cancelado() para.
• src/utils/web3.js: verificarCreditoOnchain(txHash) — read-only via Alchemy;
  receipt.status 1→"confirmado", 0→"revertido", ausente→"pendente".
• src/hooks/useCreditoStatus.js: hook que roda o polling a partir do txHash;
  estados idle/processing/confirmed/reverted/timeout; CANCELA no unmount
  (canceladoRef → sem setState após desmontar, sem timer órfão).
• src/components/CreditoStatus.jsx: feedback dos 4 estados; usa explorerTx() da
  config de rede (MC59.2) — sem host de explorer hardcoded.
• src/hooks/useTrocarPorSenhas.js: detecta 202 (status===202 || data.assincrono) →
  não afirma "creditada", devolve { assincrono:true, txHash }. Sync path INTACTO.
• src/pages/MinhaCarteira.jsx: captura o txHash do 202 e renderiza <CreditoStatus>
  (inerte com flag OFF → null). Faz o componente ser validado pelo build.
