4. CAUSA RAIZ — VARIÁVEIS ERRADAS
--------------------------------------------------------------------------------
1) RPC_URL          = https://eth-SEPOLIA.g.alchemy.com/...   (backend provider)
                      → deve ser eth-MAINNET
2) VITE_ALCHEMY_URL = https://eth-SEPOLIA.g.alchemy.com/...   (RPC do frontend)
                      → deve ser eth-MAINNET
                      CAUSA DIRETA do saldoSenhas BAD_DATA: network.js lê o contrato
                      mainnet 0x0052...16cd, mas web3.js consulta via RPC Sepolia,
                      onde esse endereço não tem código → retorna 0x.
3) CONTRATO_SEPOLIA = 0x825bBd3F...eF06 (contrato ANTIGO)
                      → deve ser 0x0052477A8CA81BCAF4a60e21e635F9e00a5d16cd (ou deletar).
                      _lib/contract.mjs resolve CONTRATO_ADDRESS =
                        CONTRATO_SEPOLIA || VITE_CONTRATO_SEPOLIA || fallback.
                      Como CONTRATO_SEPOLIA está setado, TODO o backend usa o contrato
                      antigo, não o mainnet.

VARIÁVEIS MORTAS (confirmado sem leitores em src/ nem functions/) — ignorar:
