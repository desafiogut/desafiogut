# P — Processo

Rastreabilidade, documentação, decisões.

## P1 — Toda acção rastreável
Ficheiro + linha + timestamp + commit. Sem isto, não há auditoria.
Origem: disciplina base (R3).

## P2 — Veredito documentado por segmento
Cada SEG tem veredicto SEGUIR/PARAR/AJUSTAR. Não avançar sem
veredicto.
Origem: disciplina base (R8).

## P3 — Entregáveis definidos no arranque
Listar no início o que vai ser entregue. Confirmar no fecho.
Origem: disciplina base (R9).

## P4 — Decisão do operador → 3 lugares
Registar em: `_logs/`, `CLAUDE.md`, `Desktop/RELATORIO.md`.
Origem: disciplina base (R18).

## P5 — `CLAUDE.md` actualizado antes do commit final
A fonte de verdade tem de reflectir o estado real.
Origem: disciplina base (R14).

## P6 — Skills ECC conforme mapa
Cada segmento tem skills ECC atribuídas. Não improvisar.
Origem: disciplina base (R6).

## P7 — Ritmo proporcional ao risco
UTAC pequeno → rápido. UTAC crítico → devagar. Não uniformizar.
Origem: disciplina base (R7).
