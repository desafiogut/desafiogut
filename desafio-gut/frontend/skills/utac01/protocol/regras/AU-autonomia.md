# AU — Autonomia

Até onde vai a autonomia do executor.

## AU1 — Autonomia ampliada, com parcimónia
O executor tem autonomia para corrigir o que a medição provou
errado. Mas com parcimónia — não é licença para refactorar.
Origem: disciplina base (R19).

## AU2 — Autonomia para corrigir o que a medição provou errado
Se o teste falha e a correcção é óbvia, corrigir. Se não é
óbvia, PARAR e reportar.
Origem: disciplina base (R15).

## AU3 — O executor NÃO concebe
O executor não redesenha, não adiciona features, não decide
produto. Se surgir uma ideia nova, registar como candidato a
UTAC futuro e reportar ao operador.
Origem: disciplina base (R20).

## AU4 — PARAR e reportar se ambíguo
Se algo é ambíguo, PARAR. Não improvisar. Reportar ao operador
com a pergunta exacta.
Origem: disciplina base.
